## 3. Éléments de confiance
Source : GoDaddy 2022, 204 patrons américains.
- Avis et portfolio prioritaires pour 71 % ; 64 % se méfient d'un prestataire sans avis.
- Recommandations utilisées par 73 % : parrainage et témoignages avec nom, photo et lien.
- La « vision », c'est-à-dire comprendre le métier du client, arrive en tête ; le prix bas n'a été décisif pour aucun patron interrogé.
- Ce que les douleurs font attendre : propriété des accès, prix total transparent, sans engagement, délai garanti avec pénalité, un humain joignable, pas de promesse de 1re place, résultats mesurés.
- 89 % des consommateurs attendent des réponses aux avis (BrightLocal 2025, résumé secondaire) : un argument pour inclure la gestion des avis dans l'abonnement.

Points incertains : Clutch date de 2016 ; GoDaddy Australie n'est pas datée ; les chiffres BrightLocal sont de seconde main ; Reddit n'a pas pu être consulté.
