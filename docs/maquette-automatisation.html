Pourquoi ce découpage

  • PC éteint = agents locaux arrêtés. Ce qui doit tourner la nuit (réponses, surveillance, alertes) part dans le cloud.
  • La recherche reste avec Claude : c'est le travail qui demande du jugement, et il peut attendre que vous soyez là.
  • Le fichier passe sur Google Sheets, privé : le cloud ne peut pas lire un Excel resté sur votre PC.
  • Votre accord reste obligatoire pour chaque lot, même depuis le téléphone.
